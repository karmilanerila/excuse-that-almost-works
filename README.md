The one line a gamer texts the boss to skip work during GTA 6 launch week.

The angle: a dead access badge. Badges really do die after a security
update, facilities really does take days to reissue one, and the manager
can verify it with one phone call. That is exactly why it almost works:
the only suspicious thing about it is the timing, and the timing is the
whole joke.

> My badge stopped working after the security update and facilities can't reissue one until Thursday

`main.py` writes that single line (15 words, 98 characters) to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, validating it against the gate first
(UTF-8, 1-140 characters, one line, at most 20 words) and verifying the
file after writing it. Standard library only, no network, deterministic.

Built for the [make.fun competition](https://make.fun/c/u-clever-harbor-75-the-excuse-that-almost-works-69fde8f5?ref=h379tqrk).
